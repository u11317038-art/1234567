麥克風音量互動模擬器

可使用真實麥克風、鍵盤模擬或滑桿控制音量。 空白鍵可以在「除錯模式」與「遊戲模式」之間切換。

麥克風模式需要瀏覽器授權。建議使用 Chrome，並透過 HTTPS 或 Google Apps Script 網頁部署開啟。

請選擇輸入方式。空白鍵可以切換遊戲／除錯模式。

操作說明
  1. 選擇「麥克風」，按下「啟用麥克風」，允許瀏覽器使用麥克風。
  2. 對著麥克風說話、拍手或發出聲音，方塊會依照真實音量產生浮力。
  3. 按下空白鍵可以進入遊戲模式，再按一次空白鍵可返回除錯模式。
  4. 鍵盤模擬模式可以按住 ↑ 或 W 來測試，不需要麥克風。
注意事項

麥克風資料只在瀏覽器內進行即時音量分析。 本程式不會把麥克風錄音上傳到伺服器，也不會保存錄音檔。

Chrome／Edge 通常需要 HTTPS 或 localhost 才能使用 getUserMedia 麥克風功能。

真實麥克風模式使用 Web Audio API 分析即時音量。 重新整理頁面會回到預設狀態。
